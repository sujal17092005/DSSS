BASIC DSA PROGRAMS IN C

16 standalone beginner programs. Each .txt contains C code.
To compile: rename a file from .txt to .c, then run gcc filename.c -o program
Run: ./program (Linux/macOS) or program.exe (Windows)

Topics: arrays, stack, queue, circular queue, singly/doubly linked lists, BST, graph adjacency matrix, BFS, DFS, linear/binary search, bubble/selection/insertion sort, recursion.

Graph examples use undirected edges and vertices numbered from 0. BFS/DFS visit vertices reachable from the chosen start. Binary search requires ascending sorted input.

BST UPDATE: 07 now includes inorder, preorder, postorder and a sideways tree diagram.
17 is a standalone copy of the all-traversals program; 18 has a simple tree diagram and expected outputs; 19 demonstrates level-order (BFS) traversal.
